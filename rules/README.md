# Traditional interpretation rules — editorial gate

Every approved rule MUST include:
- unique rule ID and version;
- named tradition/school and primary/credible reference;
- specific source location (chapter/page or stable canonical URL);
- exact machine-checkable predicates and exceptions;
- non-invented interpretation and a human review note;
- supported calculation input requirements;
- a link to computed evidence returned for a user.

No generic future claims or fabricated planetary positions. Do not present traditional predictions as established probabilities or guarantees.

No Vedic/Jyotish rules. Myanmar, Western, Chinese, numerology and tarot only.

**Current state:** core calculation data exists; no substantial traditional prediction corpus has yet passed this review gate.
